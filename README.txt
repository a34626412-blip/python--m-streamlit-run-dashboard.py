CHIPS Boost Live v11

Ключевое исправление v10: v10 ошибочно использовал /api/v2/promo/banners/brand/.../en как если бы это был произвольный endpoint, но затем в реальном запуске сканирование фактически уходило на chips.gg/sports/.
v11 жёстко использует API карусели Chips: /api/v2/promo/banners/brand/{brand_id}/en.

Логика:
- 1 секунда между циклами.
- Никакого открытия chips.gg/sports/.
- Берём только line_banner + view=boosted_odds.
- Сканируем весь promo payload, а не только home_top.
- Технические записи одного event_id объединяются.
- Берётся максимальный multiplier.
- Для каждого уникального event_id один раз проверяется prematch event API и кэшируется на 60 секунд.
- Прошедшие/начавшиеся события отбрасываются.
- На UI показывается только матч, время, лига и процент Boost.
- Кнопка ведёт на событие Chips.
- Нет HTTP retry queue: зависший upstream-запрос не создаёт бесконечную очередь повторов.

Запуск: run.bat
